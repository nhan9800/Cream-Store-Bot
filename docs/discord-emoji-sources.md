# Discord emoji asset sources

The campaign emoji assets `sale_cake`, `sale_party`, and `sale_gift` use the
72px PNG artwork from the jdecked/twemoji project:

- https://github.com/jdecked/twemoji
- https://github.com/jdecked/twemoji/blob/main/LICENSE-GRAPHICS

The graphics are licensed under CC BY 4.0. Product-brand emoji assets already
existed in the Cenar Store Discord server and were not downloaded by this
campaign.
